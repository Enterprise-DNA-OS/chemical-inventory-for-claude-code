# Why there is no front end

A laboratory manager can record receipts, counts, movements and follow-up by asking their coding agent. The database holds the records and produces read-only HTML for the week, stocktake, declared maxima and waste handover.

A dedicated screen gives staff mobile scanning, fast shared entry, floorplans, offline capture and access-specific views. This base does not ship those capabilities. It also does not source chemical safety data. Enterprise DNA can build the interfaces and connections around the laboratory's workflow, with access and acceptance checks before use.

The agent is the operating door. A report is a snapshot, not an emergency information service. The site owner must keep approved inventory and safety information available to emergency workers, including after evacuation. See compliance.md.
